# Notion Integration

> GameDev-Platform의 공식 문서 및 프로젝트 관리 플랫폼입니다.

---

# Overview

GameDev-Platform는 Notion을 프로젝트의 Single Source of Truth(SSOT)로 사용합니다.

Notion은 단순한 문서 저장소가 아니라 프로젝트 운영, 기술 문서, 작업 관리, 회의 기록 및 AI Agent와의 협업을 위한 중심 플랫폼입니다.

향후 MCP(Model Context Protocol)를 통해 Claude Code와 자동으로 연동됩니다.

---

# Responsibilities

Notion Integration은 다음을 담당합니다.

- 프로젝트 문서 관리
- 기술 문서 관리
- 회의록 관리
- 작업(Task) 관리
- 프로젝트 지식(Knowledge Base) 관리
- AI 기반 문서 자동화

# Long-term Goal

GameDev-Platform는 Notion을 AI Native Project Management Platform으로 발전시키는 것을 목표로 합니다.

Claude Code, GitHub, Unity 및 MCP와 연동하여 프로젝트 관리의 대부분을 자동화합니다.
