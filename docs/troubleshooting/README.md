# Troubleshooting

> 실제로 겪은 오류와 문제 해결 과정을 기록해 같은 문제를 반복하지 않기 위한 폴더입니다.

---

# Purpose

이 폴더는 미리 채워 넣는 문서가 아니라, **실제로 문제를 겪을 때마다 하나씩 쌓이는 기록**입니다.

예상되는 문제를 가정해서 미리 작성하지 않습니다. 아직 항목이 없는 것은 미완성이 아니라, 아직 기록할 만한 실제 이슈가 없었다는 뜻입니다.

---

# 기록 기준

다음 조건을 만족하는 문제만 기록합니다.

- 원인 파악에 시간이 걸렸거나, 같은 실수를 반복할 가능성이 있는 문제
- 해결 과정에서 얻은 지식이 재사용 가능한 경우 (예: 특정 MCP 서버 연결 오류, Unity/Git 환경 이슈)

단순 오타나 1회성 실수는 기록하지 않습니다.

---

# 작성 형식

파일명은 `YYYY-MM-DD-짧은-제목.md` 형식을 권장합니다.

```
# 문제

무엇이 어떻게 잘못됐는지

## 원인

## 해결

## 재발 방지
```
