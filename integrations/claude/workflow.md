# Claude Code Workflow

---

# Development Philosophy

Claude Code는 AI Agent로서 프로젝트 전반을 지원합니다.

최종 의사결정은 항상 사람이 수행합니다.

---

# Standard Development Workflow

```text
Game Designer

↓

PM

↓

Technical Lead

↓

Unity

↓

QA

↓

Documentation
```

---

# Feature Development Workflow

새로운 기능 개발 시 다음 순서를 권장합니다.

1. 기능 요구사항 정의
2. Technical Lead 검토
3. Unity 구현
4. QA 검증
5. Documentation 작성

---

# Documentation Workflow

프로젝트에서 중요한 변경 사항은 반드시 문서화합니다.

예시

- Architecture 변경
- 기술 선택
- ADR 작성
- 주요 시스템 설계
- 프로젝트 규칙 변경

---

# Claude Usage

Claude는 다음 작업을 지원합니다.

- 프로젝트 구조 분석
- 코드 작성
- 코드 리뷰
- 문서 작성
- Architecture 설계
- 테스트 지원
- 자동화 제안
