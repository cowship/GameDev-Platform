# Sprint 계획 / 우선순위 요청

**언제 사용**: Sprint를 계획하거나 작업 우선순위를 정리해야 할 때 사용합니다.

---

## `/pm` 에 붙여 쓰는 예시

```
아래 내용을 바탕으로 Sprint 계획을 세워줘.

- 목표: [이번 Sprint에서 달성하려는 목표]
- 후보 작업 목록: [작업 1], [작업 2], [작업 3] ...
- 팀 규모: [인원 수]
- 기간: [Sprint 기간, 예: 2주]
- 제약/의존성: [먼저 끝나야 하는 작업, 리소스 제약 등]

결과는 templates/sprint-report.md 형식(Summary/Goal/Priority/Action Items/Risks/Next Step)에 맞춰 정리해줘.
```

---

PM Agent는 계획/우선순위 제안만 하고 문서를 직접 만들지 않습니다([ADR 0001](../docs/decisions/0001-agent-adapter-strategy.md)의 Role Separation). 결과를 Notion Meeting Notes/Tasks Database에 남기고 싶다면 이어서 `/documentation`에 결과를 붙여 기록을 요청하세요.
